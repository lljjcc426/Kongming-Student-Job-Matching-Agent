# 孔明职配

面向学生求职场景的 AI 岗位匹配与简历优化智能体 Demo。

## 目标

帮助学生在海量岗位中快速识别与自身背景、能力专长和职业兴趣匹配度高的机会，并针对目标岗位理解简历差距、获得可执行的优化建议，从而提升通过简历初筛的命中率。

## 交付物

- 可运行 Demo：公网可访问链接。

- 演示视频：非必需，若制作则控制在 3 分钟以内。
