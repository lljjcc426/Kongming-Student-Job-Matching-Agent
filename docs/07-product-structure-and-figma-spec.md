# 产品结构与 Figma 设计规格

## 产品定位

孔明职配是面向学生求职场景的岗位匹配与简历优化智能体。产品不替代学生决策，而是将简历、岗位 JD 和求职偏好转化为可解释的匹配结果，帮助学生判断“先投什么、差在哪里、简历怎么改”。

## 核心用户路径

1. 学生导入或选择简历样例。
2. 系统生成学生画像：专业背景、项目经历、技能标签、求职兴趣。
3. 学生浏览岗位推荐列表，选择目标岗位。
4. 系统输出匹配分、五维评分、关键词覆盖与风险提示。
5. 系统生成简历优化建议、项目经历改写方向和投递行动清单。

## 信息架构

### 顶部区域

- 产品名称：孔明职配
- 当前状态：Demo 模式 / 可解释匹配 / 学生求职场景
- 主操作：开始分析、导入简历、查看方案说明

### 左侧：学生画像

- 基本信息：姓名、年级、专业、目标方向。
- 能力标签：前端、数据分析、产品分析、AIGC、用户研究等。
- 经历证据：课程项目、竞赛、实习、校园经历。
- 求职偏好：岗位类型、城市、行业兴趣。

### 中间：岗位匹配

- 岗位卡片列表：岗位名称、方向、城市、匹配度、推荐优先级。
- 选中岗位详情：岗位职责、硬性要求、加分项、关键词。
- 五维评分：能力匹配、经历匹配、关键词覆盖、兴趣一致、成长潜力。
- 多智能体协作台：展示简历解析、岗位搜索、策略建议、模拟面试和协作监督的输出。

### 右侧：AI 优化建议

- 匹配结论：推荐投递 / 谨慎投递 / 暂不优先。
- 差距解释：缺失技能、经历表达不足、关键词覆盖不足。
- 简历优化：STAR 改写建议、关键词补齐建议、项目表达建议。
- 行动清单：投递前 24 小时内可完成的具体动作。

## 视觉方向

### 设计关键词

- 专业、清晰、可信。
- 信息密度适中，适合评委快速理解产品闭环。
- 避免过度娱乐化和不严肃表达。

### 布局

- 桌面端采用“顶部说明 + 四步流程 + 三栏工作台”：左侧画像，中间岗位匹配，右侧初筛优化建议。
- 移动端改为纵向堆叠。
- 卡片用于岗位、建议、经历证据等重复信息；不使用嵌套卡片。

### 色彩

- 主色：蓝色，用于强调“专业、可信、分析、决策”。
- 主背景：浅蓝白，形成干净的求职工作台氛围。
- 辅助色：浅蓝与白色用于承载信息层级，琥珀色用于风险提醒，红色仅用于低匹配风险。
- 背景：浅灰白，保证内容可读性。

### 组件

- 岗位卡片：显示岗位名、方向、城市、匹配分和优先级。
- 能力标签：用于展示学生技能和岗位关键词。
- 评分条：展示五维匹配结果。
- 雷达/条形图：用于匹配维度可视化。
- 建议列表：每条建议包含问题、依据和行动。
- 四步流程条：展示学生画像、岗位捕手、初筛优化、投递行动的闭环。
- 智能体卡片：每个智能体展示职责、证据、产物和下一步动作。

## 首版 Demo 范围

- 使用内置学生画像和岗位样例。
- 支持切换岗位并实时刷新评分和建议。
- 支持编辑简历文本，生成简历摘要和关键词覆盖。
- 使用本地规则引擎生成匹配结果，保证无 API Key 时也能运行。
- 页面文案保持克制，不承诺真实录用结果。
