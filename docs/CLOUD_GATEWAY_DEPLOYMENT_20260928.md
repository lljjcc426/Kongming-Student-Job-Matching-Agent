## 内测维护边界

- 开发机更换网络、出口 IP 改变，或真机使用移动数据时，现有 `/32` 规则不会自动放行；需要同时更新安全组与 Nginx 允许来源，不能只改其中一处。
- 80 端口保持公网可达供证书续期验证，但业务路由禁止明文访问。不要删除证书路径或关闭 80 后仍假定自动续期可用。
- 后端仍只监听 `127.0.0.1:8787`；无需开放 `5173` 或 `8787`。
- HTTPS 根路径没有网页，直接在浏览器打开服务器 IP 返回 `404` 属于当前 API-only 部署设计。
- 自动续期机制已配置并模拟验证，但未来是否成功仍依赖网络、证书验证路径和服务状态；还未配置独立的过期/费用告警。
