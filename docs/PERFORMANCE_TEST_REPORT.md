# 性能测试报告

当前文件为性能测试报告模板。提交前需要根据最终运行环境补充真实测试结果，不能使用估算数字或编造数据。

## 1. 测试目标

验证 Kongming Student Job Matching Agent 在评审环境中的可用性、响应速度和稳定性，重点关注：

- 页面是否能正常加载。
- 简历上传和结构化解析是否可用。
- 岗位推荐和 JD 分析是否能完成。
- 模拟面试和 AI 助手是否能返回结果。
- 模型请求是否稳定，是否存在明显超时。

## 4. 测试命令

依赖安装：

```bash
npm install
```

构建验证：

```bash
npm run build
```

解析器验证：

```bash
npm run verify:parsers
```

UI 验证：

```bash
npm run dev
npm run verify:ui
```

注意：`npm run verify:ui` 需要开发服务器运行在 `http://localhost:5173`。

## 8. 已知限制

当前已知限制：

- 仓库未实现持久化性能日志，需要人工或部署平台日志辅助统计。
- `verify:ui` 使用 Mock 模型响应，不代表真实模型延迟。
- 浏览器语音识别能力受浏览器、系统权限和网络环境影响。
- Live2D 加载和渲染性能受浏览器 GPU 和资源加载影响。
