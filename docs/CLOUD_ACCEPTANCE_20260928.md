- 横屏文字回答：键盘显示状态原先改变输入面板所在 UI 分支，导致 TextArea 重建并丢失焦点。改为固定同一 Row 中的唯一面板，键盘出现时仅调整尺寸。
- 报告分项评分：总分已收到云端新结果，但分项 Builder 使用初次传入的数字，继续展示旧本机分数。改为在 Builder 内依据维度读取当前评估状态，使数字和进度条同时刷新。
- 增加这两项结构性回归断言；实际交互正确性另由独立模拟器复测证明。
- 云端岗位测试首次出现一次 `fetch failed`，重试成功；未定位最初原因。测试脚本补充 operation 和底层错误诊断，不输出模型凭证。
