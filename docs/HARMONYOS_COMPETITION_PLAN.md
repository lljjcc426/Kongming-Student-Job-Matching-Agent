# 孔明职配鸿蒙高校创新赛任务链

更新时间：2026-07-17

官方入口：[鸿蒙高校创新赛](https://developer.huawei.com/consumer/cn/activity/incentive/C4)。当前开发以 2026 年赛程与官方最新稳定 HarmonyOS 工具链为准；时间节点如有变化，以官方页面为准。

## 1. 产品定位

孔明职配是一款面向求职者的信息收集、岗位理解、简历编辑与投递准备应用。第一阶段优先服务互联网企业岗位，同时保持产品、研发、设计、数据、运营等方向的广覆盖，不做蓝领兼职，不做企业端。

核心差异化：

1. 真实岗位：只展示企业官方公开接口或官方岗位页可核验的数据，并保留来源、更新时间与采集时间。
2. 可解释匹配：展示简历中的命中证据、缺失证据和可迁移能力，不输出无法验证的“录用概率”。
3. 证据约束 AI：改写只能引用简历中已有事实；缺少的数据要提出补充问题，不能编造经历或数字。
4. 本地优先隐私：无网仍可编辑简历和执行本地匹配；上传模型必须由求职者主动授权。

## 2. Web 到鸿蒙的能力映射

| 原生能力 | 用户价值 | 验收方式 |
| --- | --- | --- |
| Share Kit 系统分享接收 | 浏览招聘网页时一键把岗位链接或文本送入收集箱 | 浏览器分享文本后，孔明职配出现在系统分享面板并读取内容 |
| ArkWeb 本地资源包 | 最大限度复用现有 UI、品牌素材和业务流程 | 断开远程网页后 HAP 仍能启动五个核心页面 |
| Web 响应式布局 | 沿用现有手机适配，逐步补充平板/2in1 | 手机核心操作无截断，宽屏布局后续专项验收 |
| Core File Kit 系统文件选择器 | 从本机选择 TXT/Markdown 简历，不申请宽泛存储权限 | 选择文件后正文进入事实编辑区 |
| Network Kit | 获取企业官方公开岗位和可选模型增强 | 展示官方来源、更新时间、失败降级提示 |
| App Linking / 系统浏览器 | 从岗位卡片返回企业官网核验和申请 | “查看官网”打开对应官方岗位详情 |

## 4. 演示主线

1. 在招聘网页选中一段 JD，通过系统分享发送到孔明职配。
2. 应用从企业官方招聘源采集同方向真实岗位，展示来源和更新时间。
3. 用户导入本地简历，在手机单列或平板双栏中编辑并实时预览。
4. 用户主动开启一次云端授权，AI 只基于证据改写；关闭网络后仍可编辑并得到本地提示。
5. 选择岗位查看命中证据、缺失证据与迁移能力，最后跳回企业官网核验。

## 5. 明确不做

- 第一阶段不做企业招聘端。
- 不做自动投递、批量海投或绕过招聘平台限制的爬取。
- 不抓取求职者、招聘人员的个人信息。
- 不用静态样例冒充实时岗位。
- 不承诺录用结果，不把模型生成内容当成事实。
