# 孔明职配方案说明

## 问题诊断

学生求职的核心困难不是“缺少岗位信息”，而是信息过载、岗位理解不足和简历表达与岗位要求脱节。普通岗位检索只能给出职位列表，无法解释匹配原因；单次简历点评也难以联动岗位推荐、JD 分析和面试准备。因此，本项目将求职流程拆成“简历理解-岗位发现-匹配评估-优化建议-模拟面试-自由问答”的连续工作流。

## 方案设计

孔明职配是一款面向学生求职场景的 AI 智能匹配工具。系统支持 PDF、图片和文本简历导入，先抽取学历、实习经历、项目经历、校园经历、荣誉证书、技能与求职意向，再由岗位推荐智能体生成候选方向，并结合学生自定义 JD 进行二次评估。前端包含首页、简历解析、岗位推荐、模拟面试和 AI 助手五个页面，既能完成结构化分析，也能提供连续对话式求职咨询。

## AI 工具选型理由

模型层选择具备文本理解与视觉识别能力的大模型，通过后端代理统一调用，避免密钥暴露在前端。PDF 解析采用 PDF.js 文本层与页面视觉识别混合策略：文本层质量足够时直接结构化，文本层缺失中文主体或简历关键信号时自动转视觉识别。语音交互使用浏览器 Web Speech API 作为轻量方案，便于在公网 Demo 中快速体验。

## 关键配置

前端使用 React、TypeScript、Vite 与 Tailwind CSS，部署在 Vercel。模型请求经 `/api/ark` 代理转发，设置请求体大小限制、超时控制和安全响应头。简历图片会在浏览器端压缩，PDF 页面按页拆分识别，避免单次多图请求导致超时。解析器对模型 JSON 结果增加格式修复与字段级兜底，提升稳定性。

## 迭代记录

项目从静态 UI 原型迭代为可运行 Demo，先完成五页面产品结构，再接入模型代理、简历解析、岗位推荐、JD 分析、AI 助手和模拟面试。后续重点优化了首页动效、响应式布局、PDF 视觉兜底、Markdown 渲染、语音转写稳定性，以及模拟面试中综合面、技术面、HR 面的差异化提示词。

## 效果评估

当前 Demo 已支持公网访问，能够完成从简历上传到岗位推荐、建议生成和模拟面试的闭环。针对复杂 PDF、图片简历和长对话场景，系统增加了分步进度、错误兜底和可编辑输入，降低失败率。仍可继续增强真实岗位数据源、简历改写生成、视频数字人和投递状态追踪，使产品更接近真实求职工具。
