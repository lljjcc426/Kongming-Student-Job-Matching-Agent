## 4. 后续 QA 填写规则

- 每轮 Codex 任务结束后追加一行。
- 只填写真实执行过的检查和验证。
- 不编造 commit。
- 不编造验证结果。
- 不编造 Demo 链接。
- 不编造性能数据。
- 不编造真实调用日志。
- 如果验证失败，必须写明失败原因。
- 如果本轮没有修改代码，应在“修改文件”中明确只写文档路径。
- 如果 GitLink Issue 后续未创建，应保持“可选补充项”口径，不写成必需材料。
