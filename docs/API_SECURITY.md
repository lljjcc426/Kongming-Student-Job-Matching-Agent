# 公共网关安全边界

## 结论

Web 或原生客户端只要需要联网，请求地址就能被开发者工具、代理或安装包分析看到，因此不能依赖“隐藏 URL”保护后端。当前实现只向客户端公开 `/api/gateway`，真正的安全边界是服务端鉴权、来源策略、限流、输入校验、错误脱敏和凭证隔离。

## 客户端可见内容

- 唯一公共网关地址；
- `jobs`、`status`、`model` 三个公共操作名；
- 岗位结果及其公开来源、能力可用布尔值和生成内容；不包含模型供应商或模型名称。

## 客户端不可包含内容

- 讯飞、Ark/Gitee AI 或其他供应商密钥；
- 供应商 HTTP/WebSocket 地址和短时签名 URL；
- 内部 Provider ID、鉴权模式、环境变量名和底层错误；
- 岗位来源耗时、失败栈、仓库统计等运维结构。

## 已实现控制

- 生产和开发环境复用 `server/publicGateway.js`；
- 浏览器仅允许同源或 `PUBLIC_APP_ORIGINS` 精确白名单，不使用 `Access-Control-Allow-Origin: *`；
- HarmonyOS Network Kit 的无 `Origin` 请求可访问，但仍受方法、内容类型和限流约束；
- 模型操作只接受 `POST application/json`，岗位和状态操作只接受 `GET`；
- API 请求体限制为 8 MB；
- 岗位、状态和模型操作使用独立频率限制；
- 服务端错误统一转换为公共错误，不透传供应商配置和上游地址；
- 旧模型、岗位、健康和来源状态路由不再部署。

## 生产上线前必须补齐

1. 使用华为账号登录令牌或服务端签发的短时会话令牌，并在服务端验证用户身份；不要把静态共享密钥写入 HAP。
2. 将当前进程内限流替换为 Redis、KV 或云 WAF 的分布式限流，并按账号、设备风险和 IP 联合计数。
3. 给模型调用设置每日配额、单次成本上限、并发上限和异常熔断。
4. 日志只记录 requestId、操作、状态、耗时和脱敏后的错误分类，不记录简历正文、回答、令牌或完整请求体。
5. 轮换任何曾通过聊天、截图、工单或日志传递的真实凭证，并在部署平台 Secret 管理中保存新凭证。
6. 发布前扫描 Web `dist/` 与 HAP，确认不包含凭证、供应商端点和已关闭的旧路由。

注意：CORS 只限制浏览器跨域读取，不是身份认证，也不能阻止脚本或代理直接请求公共网关。
