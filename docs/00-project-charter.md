# 项目任务书

## 项目名称

Offer Catcher AI

## 参赛课题

作业一：「Offer 捕手」学生求职匹配智能体。

## 问题背景

学生在求职过程中通常面临两个核心问题：

1. 岗位信息量大，难以快速判断哪些岗位与自身背景、能力专长和职业兴趣真正匹配。
2. 面对感兴趣岗位时，不清楚简历与岗位要求之间的差距，也缺少具体、可执行的简历优化建议。

## 产品目标

设计并搭建一个 AI 求职匹配智能体，帮助学生完成从“理解自己”到“筛选岗位”再到“优化简历”的闭环：

- 结构化识别学生画像。
- 多维度评估岗位匹配度。
- 解释匹配与不匹配原因。
- 给出面向目标岗位的简历优化建议。
- 输出适合学生执行的求职行动清单。

## 目标用户

- 主要用户：正在寻找实习、校招或转岗机会的在校学生。
- 辅助用户：就业指导老师、职业发展顾问、校园招聘运营人员。

## Demo 边界

首版 Demo 聚焦“学生端求职决策与简历优化”，不做自动投递、不做真实招聘平台账号登录、不承诺替代企业筛选结果。

## 成功标准

- 用户可以输入或上传简历内容，并选择或粘贴目标岗位。
- 系统可以输出岗位匹配评分、评分解释、能力差距、关键词缺口和简历优化建议。
- Demo 页面完整、交互连贯、结果可解释，适合 3 分钟内完成演示。
