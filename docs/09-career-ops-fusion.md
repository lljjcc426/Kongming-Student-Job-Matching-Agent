# career-ops 参考融合记录

## 参考对象

- 仓库：santifer/career-ops
- 参考重点：岗位评估报告、定制化简历思路、申请流程追踪、数据边界设计

## 已融合内容

1. 岗位深度评估
   - 在岗位推荐页新增“岗位深度评估”。
   - 输出岗位理解、投递节奏判断和定位策略。

2. 要求匹配表
   - 将目标岗位要求拆成匹配条目。
   - 每条给出匹配状态、简历证据和补强方向。

3. 投递运营看板
   - 在初筛建议区新增简历解析、岗位评估、材料定制、投递跟进四个阶段。
   - 用于呈现从分析到投递的行动闭环。

4. 报告导出增强
   - 下载的 Markdown 报告新增岗位深度评估、要求匹配表、定位策略和投递运营看板。

## 未直接采纳内容

- Go TUI 工作台：与当前 Web Demo 形态不一致。
- Claude Code modes：与当前 Doubao API 服务端代理架构不一致。
- 自动批量投递：存在求职合规和用户授权风险，本项目保留人工确认与跳转入口。

## 产品价值

本次融合让产品从“单次简历匹配”进一步扩展为“岗位判断、材料定制、投递跟进”的轻量求职运营工作流，更贴近学生真实求职过程，也更利于展示 AI 辅助决策的可落地性。
