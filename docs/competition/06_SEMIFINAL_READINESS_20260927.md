### P0-A：让评审能独立运行

1. 确认评审设备。目前工程兼容 SDK 和目标 SDK 均为 HarmonyOS 6.1.1(24)，不能默认旧设备可安装。
2. 按组委会认可方式准备签名、安装步骤、权限和系统说明。当前 signingConfigs 为空。规程没有把上架或某一种生产签名写成唯一门槛，但必须在约定环境可靠演示。
3. 展示在线岗位和星火面试，需要评审期间可用的 HTTPS 网关，并重新构建注入地址的 HAP。10.0.2.2 是当前模拟器访问宿主服务的专用地址，不能作为独立评审方案。
4. 只做最小评审服务，不等于完成商业化部署。配置临时访问授权、额度和并发边界、错误脱敏及服务端凭证；不能在 HAP 写共享密钥，也不能用 CORS 代替鉴权。
5. 用最终包在非开发环境完成清洁安装、岗位查询和一次完整在线面试，留存脱敏调用证据、版本、哈希和构建时间。
6. 提供匿名测试简历和来源可追溯的 JD。预置岗位、本机规则和录像回放必须说明来源，不能伪装为实时在线 AI。

### P0-B：真机主线与语音验收

建议至少测试一台支持目标版本的华为真机：横竖屏切换、键盘遮挡、权限拒绝与恢复、语音识别和播报互斥、数字人加载、连续会话、暂停/重启、PDF 保存/分享。真机不是规程列出的提交资格门槛；官网 FAQ 允许自有设备、DevEco Studio 官方模拟器及云测试资源。模拟器不能证明它不支持的真实麦克风、摄像头和系统能力已经通过验收。

展示相机与录像时，还需验预览、录制、回放和删除。不稳定时缩减演示范围，不宣称已经验证。账号、OCR、日历和卡片凡作为已完成特性展示，都应有对应运行证据。

NativeCapabilityService.ets 当前采音循环上限为 15 秒。需检查是否截断面试回答；可采用提示清楚的分段输入、识别后编辑及文字兜底。不要未经验证宣称长时连续实时语音面试。星火文本面试、鸿蒙 Core Speech 和第三方语音大模型是不同能力。

### P0-C：材料对齐最终包

使用官方模板重组研发文档，不直接提交竞争研究报告或 README 代替作品说明。截图和视频使用当前原生版本，不夹杂旧 Web、旧人物或后台配置面板。准备干净的匿名演示工作区；演示在线和降级状态时如实说明来源。

### P0-D：原创、许可和隐私

已有 Web 基础，需列出参赛期原生化、证据闭环和岗位驱动面试的新增时间线，以提交记录、架构差异和测试证明原创贡献，而不是宣称从零开发全部技术。

当前 Rocketbox 角色与办公室 V3 已有许可记录；许可汇总仍有部分旧 Web 图片、视频和 Live2D 来源待确认。最终包及成片只放来源确认的实际使用素材。应用方向不必打包整个含旧素材的历史仓库；若申报 Agent 或后台额外要求源码，则核对必须提交的工程和资产。

如该产品曾在同类同级赛事获奖，需要说明本次实质技术突破。公共材料不得包含真实简历、模型密钥、证书私钥、Cookie 或原始相机画面。曾在聊天中传递的真实凭证应在评审服务上线前轮换。

## 4. 按评分组织亮点

规程第 6 页基础分：创新性 50、完备度 20、前景评估 20、规范性 10；另有实际应用价值附加分 20。各阶段单独评分。提交可运行包不等于必然拿满附加分。

建议一句话定位：面向高校学生，以简历事实证据约束岗位准备，串联岗位驱动的原生数字人面试、复盘与成长任务的鸿蒙求职工作台。

只重点讲三项有实现证据的创新：

1. 事实约束与版本绑定：无证据经历不自动写入；岗位要求、证据缺口和正式投递版可追溯。
2. 岗位驱动面试与成长：基于 JD、绑定简历与原回答追问；复盘形成行动任务，仅满足条件的同岗位记录比较变化。
3. 鸿蒙原生任务连续性：数字人、Core Speech、Form Kit 和系统能力服务求职场景，不是 Web 套壳或 Kit 名称堆砌。

应用方向建议集成 3 个及以上鸿蒙特性，不是规程写明的资格硬门槛。选择可演示特性配证据；多尺寸适配不等于分布式跨端协同，源码调用链不等于真机验收。

前景评估建议用 3 至 5 名目标学生真实试用补证，记录任务完成率、耗时、问题及访谈反馈并注明样本量。不虚构用户数、满意度、就业改善或收入；证据覆盖率、训练分不是录用率或第三方能力认证。

## 5. 文档和视频方案

优先遵循官方模板，不删除必填项。主体建议 12 至 16 页，20 页只是上限：

- 痛点、学生需求、创新定位和场景：2 至 3 页。
- 主流程与当前原生界面：3 至 4 页。
- 原生架构、鸿蒙特性、AI 与隐私边界：3 至 4 页。
- 测试实测、需求真实性、落地前景与团队贡献：3 至 4 页。
- 许可、参考资料、详细测试及额外截图放附录，不把全部创新论证藏入附录。

设计稿主线：匿名简历确认 -> 国内真实岗位 -> 证据缺口 -> 正式版本/投递 -> 横屏岗位面试 -> 逐题复盘 -> 成长任务/卡片。

建议视频成片 4 分 40 秒：

| 时间 | 内容 |
| --- | --- |
| 0:00-0:20 | 学生痛点与一句话创新 |
| 0:20-1:00 | 简历、国内岗位和证据缺口 |
| 1:00-1:40 | 岗位专属版本、本人确认、PDF 和投递绑定 |
| 1:40-3:10 | 横屏数字人面试、回答和个性化追问 |
| 3:10-3:50 | 逐题复盘、同条件对比与成长行动 |
| 3:50-4:20 | 已验收的卡片或系统能力，展示任务连续性 |
| 4:20-4:40 | 实测证据、原创贡献和能力边界 |

可剪辑，但不能用剪辑掩盖失败并把离线结果伪装为在线。不需要凑满 5 分钟。
