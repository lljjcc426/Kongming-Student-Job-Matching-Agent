## 2. 关键可信性断言

- 未确认简历不能直接通过硬性学历门槛。
- 用户确认后证据强度会提高，但仍不表示录用概率。
- “尚未使用 Python”不能被识别为掌握 Python。
- 重复无关文字不能提高证据覆盖率。
- 城市偏好不能改变专业要求覆盖率。
- 缺少的 SQL 不能进入当前简历技能栏。
- 医学 JD 不能套用通用互联网关键词。
- 模型生成职业方向不能带投递链接。
- 手机号、邮箱、身份证、地址和姓名均可被统一脱敏。
- 职业方向不能进入求职投递追踪。
- 追踪阶段变更保留追加式事件历史，并能从本机存储恢复。

## 3. UI 回归摘要

- 外部模型隐私选项：5 项。
- 测试请求敏感数据泄漏：未发现。
- 三类岗位页签：已验证岗位、我的 JD、职业方向。
- 测试简历确认前证据覆盖：50%；确认后：100%。该结果只说明测试夹具中三项可评估要求均有确认事实。
- 简历改写建议：支持逐条接受。
- 求职追踪：阶段 `applied` 成功写入本机存储。
- 面试页和 AI 助手按需加载后仍通过页面断言。
