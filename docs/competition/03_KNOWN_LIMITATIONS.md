# 已知限制与风险

## P0：提交前必须处理

1. 当前 HAP 是 unsigned 调试产物，没有正式签名配置，不能直接用于应用市场发布。
2. 本轮 HAP 未注入公网 `VITE_ARK_API_URL` 和 `VITE_JOBS_API_URL`；`file://` 环境不会自动使用开发机的相对 `/api`，因此在线岗位与模型能力需要 HTTPS 服务地址或本地调试反向端口。
3. Core Vision 与 Share Kit 已通过编译，但尚未使用真实图片与系统分享动作完成运行时验收；模拟器或部分设备可能缺少对应系统能力。
4. 华为账号依赖控制台授权、包名与签名指纹一致；unsigned 包不能代表发布态登录已经完成。

## P1：影响体验但有降级

1. 核心业务页面仍为 ArkWeb 混合实现，ArkUI 只承担原生容器和桥接。
2. Core Speech 尚未接入；当前语音输入依赖 Web Speech 兼容能力，不同设备表现可能不同。
3. Form Kit 今日行动卡片尚未实现，本机待办只在应用内展示。
4. PDF 扫描页会优先本机 OCR；本机能力不可用且用户不同意外部模型时，只能提示改用文本版简历。
5. 当前求职追踪是单设备本机数据，没有跨设备同步、账号云备份或团队协作。

## P2：后续优化

1. 安装包包含视频、图片、PDF.js 和 3D 资源，体积约 34.2 MB；大型页面已按需加载，但静态媒体仍可继续压缩。
2. 企业官方岗位采集是请求时聚合与可选 JSON 快照，不是大规模实时数据库；需要健康检查、限流和关闭岗位对账。
3. 模型输出仍受模型质量影响，必须保持用户确认和原文证据引用。
4. 当前不实现企业端、招聘平台账号连接、自动投递和批量海投。

## 风险表述规则

- “已接入”表示存在源码并通过构建；“已验证”必须另有运行或测试证据。
- “证据覆盖率”不能写成“录用率”“通过率”或“匹配成功率”。
- “职业方向”不能写成“实时岗位”。
- “本机 OCR 优先”不能写成“所有图片永不出端”；外部兜底仍可能在用户同意后发生。
