# 已知限制与风险

## P0：发布前必须完成

1. 当前 HAP 是 `appSignType: none` 的 unsigned 调试产物，已完成 ArkTS 编译、模拟器安装和原生入口启动，但尚未完成真机验收，不能作为应用市场发布包。
2. 默认离线 HAP 不注入公网服务地址；普通用户安装包必须改用可公开访问的 HTTPS 岗位、模型和健康检查地址。当前原生 AI 面试只在无 `ARK_API_KEY` 环境验证了可信降级，尚未取得真实模型成功调用证据。
3. 华为账号需要 AppGallery Connect 授权、包名、证书和签名指纹一致；unsigned 模拟器结果不能代表账号登录可用。
4. Core Vision、Share Kit 和 Core Speech 已进入 ArkTS 调用链并通过编译；模拟器已验证 OCR 图片 URI 读取和稳定降级，但尚未在支持相应能力的真机完成完整交互验收。
5. Form Extension 已在模拟器安装信息中注册，尚未取得“桌面添加—应用内变更—卡片刷新—杀进程—再次点击”的完整证据。
6. 赛题是否要求发布、允许的分发方式、最终材料格式和截止时间必须以当届官方页面为准。

## P1：核心体验限制

1. 主工作台已迁移到 ArkUI/ArkTS 原生页面；本轮已完成 DevEco 编译、unsigned HAP 打包、模拟器安装和入口启动，尚未完成真机/多设备验收。
2. 简历和投递数据保存在单设备本机，没有跨设备同步、云备份和账号恢复。
3. 事实约束能阻止系统自动写入无证据内容；原生成长账本会用 Network Kit 核验公开 HTTPS 来源可访问并保存状态码，但 `HTTP 200` 只说明该地址在核验时可访问，不能证明仓库权限、提交归属或材料真实性。用户手动确认的信息真实性最终仍由用户负责，应用不是背景调查系统。
4. 岗位采集使用请求时聚合和可选 JSON 快照，不是大规模实时岗位数据库。企业页面改版、限流或反爬会导致来源失效。
5. 健康检查能提示服务降级，不能保证模型和岗位来源随后一直可用。
6. 账号、语音和分享已由原生页面直接调用；图库和文件选择器已接入，图片 URI 已能在本机读取并进入 Core Vision 调用链，但当前模拟器缺少 OCR 实现，支持设备上的实际识别结果仍需真机验收。
7. 原生 AI 面试支持最多三轮文本追问和最终反馈，但当前不做流式输出、断点续传或离线模型推理；网络或服务配置失败时使用确定性本机规则。
8. 成长证据来源核验使用 `HEAD` 请求，部分禁止 `HEAD` 但允许浏览器 `GET` 的站点可能产生假阴性；内容指纹是本机确定性摘要，不是数字签名、时间戳服务或第三方认证，跨设备同步和防篡改存证尚未实现。

## P2：后续优化

1. 当前原生 unsigned HAP 约 1.0 MB，默认不包含 Web 静态资源；后续接入图片、岗位缓存和演示素材时仍需控制安装包体积。
2. 当前版本差异使用按行新增/删除摘要，不是文字处理软件级的逐字修订视图。
3. 服务卡片当前展示阶段化下一行动，可在摘要中带出截止或面试时间，但尚未接入系统日历提醒，也未完成桌面动态刷新验收。
4. 暂不实现企业端、招聘平台账号连接、自动投递、批量海投或爬取需要登录的个人页面。
5. 正式运营还需补充隐私政策、用户协议、数据保留周期、账号注销、未成年人处理、监控、限流和安全审计。

## 仓库体积

公开页面显示的仓库总体积包含历史 Git 对象，不能只通过删除当前工作树文件立即下降。本轮没有提交 HAP、模拟器镜像、`dist/`、运行日志或 `artifacts/`；主要大文件仍是演示 PPT、Live2D 模型和媒体资源。后续若要显著缩小历史仓库，需要单独评估 Git LFS 或历史重写，这属于破坏性操作，不能在普通功能提交中直接执行。

## 表述规则

- “已实现”表示源码存在；“已构建”表示编译/打包通过；“已验证”必须有自动化或运行证据。
- “证据覆盖率”不能写成录用率、通过率、能力分或匹配成功率。
- “职业方向”不能写成实时岗位。
- “官方岗位”表示来源链接可追溯，不保证企业此刻仍开放；必须结合状态和最后发现时间。
- “本机 OCR 优先”不能写成所有图片永不出端；用户同意后仍可能使用外部视觉模型兜底。
- “原生 AI 链路已实现并编译”不能写成“真实模型调用已验证”；后者必须提供当前 HAP 对应的脱敏请求、成功响应或服务端调用记录。
- unsigned 模拟器 HAP 不能写成可发布应用。
