# 孔明职配原生离线预审包

本包只供开发及模拟器预审，不是正式参赛提交包。Release 编译不等于签名发布。应用创新赛道，队伍为南山冯诺依曼；包内 manifest.json 的 readyForSubmission 固定为 false。

## 文件范围

- app/entry-default-unsigned.hap：ArkUI/ArkTS 原生 Release HAP，无旧 Web 主界面。
- demo/：人工构造的匿名简历和 JD，供手动粘贴测试，不是真实学生资料或招聘信息。
- licenses/：项目来源、Apache-2.0、NOTICE、角色 MIT 许可及本机 PDF 依赖许可。
- manifest.json：包内文件大小、SHA-256、版本、API、提交阻塞项。

不会打包整个仓库、环境变量文件、签名私钥、真实简历、用户本机状态或相机画面。角色为 Rocketbox v5，办公室为 V3；未使用的旧角色和旧办公室已在构建暂存区排除，不删除源文件。剩余原生品牌图标和前景素材的来源仍需团队核实，不能理解为全部资产已经完成法律审查。

## 环境及安装

使用 DevEco Studio 6.1.1 与 HarmonyOS API 24 官方模拟器。本包 minAPIVersion 和 targetAPIVersion 为 60101024；不承诺旧版系统、真机或评审设备可直接安装 unsigned HAP。先核对 ZIP 的 .sha256，再解压到 D 盘。

模拟器已连接 HDC 时，在解压目录执行：

```powershell
$hdc = 'D:\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc list targets
& $hdc -t '<实际设备标识>' install -r '.\app\entry-default-unsigned.hap'
& $hdc -t '<实际设备标识>' shell aa start -a EntryAbility -b cn.kongming.jobmatch
```

保留安装与启动结果。如果系统拒绝未签名 Release 包，不要通过修改系统校验或滥用证书绕过；使用团队开发签名并重新构建，或按组委会认可的评审安装方式办理。源工程位于 harmony/，不是仓库根目录。首次打开 DevEco 工程需自行确认信任提示。

覆盖安装可能保留已有工作区；不等于清洁安装验收。需要干净测试时使用单独模拟器实例。不要删除包含真实简历的用户实例，也不要将现有私人工作区复制进评审包。

2026-09-27 本机实测：当前 Release unsigned HAP 在 KongMing_API24 官方模拟器覆盖安装成功，解锁后 EntryAbility 启动成功，首页渲染可见。现有本机资料保留，未执行卸载、数据清除或清洁安装。这不证明正式评审设备、真机签名、公网 AI 或全部功能已通过验收。

## 离线测试路径

1. 在简历页手动粘贴 demo/anonymous-resume.txt 中标记为输入正文的段落，目标方向填写“鸿蒙应用开发实习生”。不要用私人简历。
2. 岗位页新增“人工构造测试企业”的岗位，粘贴 demo/synthetic-jd.txt 的输入正文。保留“人工构造 / 不用于求职”的标识，来源链接留空；不要把样例冒充平台检索结果。
3. 查看岗位要求与缺口，编辑独立岗位材料。冻结、绑定版本后，在核对事实的测试流程中确认正文，再生成本机 PDF。
4. 从当前岗位进入横屏面试，使用文字作答，完成逐题复盘，再查看成长任务和历史记录。评分只用于检查流程，不是能力认证或录用概率。
5. 在非面试进行状态正常退出后重启，检查本机资料恢复。卡片入口、权限拒绝和系统能力在设备支持范围内另行检查。

本包未注入公网网关，不能独立展示实时岗位检索或星火在线追问。查询失败或明确本机降级是当前预期边界，不可录制为“在线 AI 全流程”。语音使用鸿蒙 Core Speech，当前采音上限 15 秒，不是讯飞语音大模型。相机和录音需要用户主动授权，模拟器结果不等于真机验收。
